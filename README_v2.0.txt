峻爸 AI智慧照片分類器 v2.0
製作人／程式所有人：峻爸

本版重點
- 標準模式、進階模式整合在同一個 EXE，直接切換。
- 快速掃描預覽：先分析，不複製、不移動、不刪除原始照片。
- 預覽後可依人數、場景、日期、關鍵字篩選，再選取要輸出的照片。
- 只有按「輸出選取照片」後才會複製原圖。
- SQLite 快取：同一批未變動照片再次掃描可直接讀取結果。
- 標準模式：人數、日期、場景、AI內容標籤。
- 進階模式：標準功能 + ArcFace 指定人物比對、多參考照模板、臉部品質檢查。
- 人物結果分為：高度符合、疑似符合、低品質待確認、不符合。
- 輸出可選：不分類、依人數、依年月、依場景、依指定人物結果。
- EXE 操作面板與視窗標題均顯示「製作人／程式所有人：峻爸」。

GitHub 編譯
1. 將本 ZIP 解壓後的所有檔案上傳到 GitHub Repository。
2. 確認 .github/workflows/build-windows-v2.0.yml 存在。
3. GitHub → Actions → Build JunBa AI Photo Classifier v2.0 Windows EXE。
4. Run workflow。
5. 完成後到 Artifacts 下載 JunBa-AI-Photo-Classifier-v2.0-Windows-Portable。
6. 內含：峻爸_AI智慧照片分類器_v2.0.exe

建議操作
來源資料夾 → 快速掃描預覽 → 套用篩選 → 雙擊列選取（✓）→ 輸出選取照片。

注意
- 大合照極小臉、嚴重模糊、遮臉、極端側臉仍可能漏判。
- 指定人物相似度只適合照片整理，不作身分、法律或門禁證明。
- 疑似符合、低品質待確認建議人工確認。
- 場景與內容標籤屬 AI 輔助分類，請先看預覽再輸出。
- 若要公開散布或商業使用，請另行確認所使用 AI 模型的授權條件。
